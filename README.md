# Streak Sprite

Streak Sprite is a habit and task tracking web application built using Lovable and Supabase.

## Purpose
The purpose of the app is to help users organize daily habits and tasks in one place.

## Features
- Login and signup
- Add habits and tasks
- Edit and delete items
- Mark items as completed
- Persistent data storage using Supabase

## Technologies Used
- Lovable
- Supabase
- JavaScript
- HTML/CSS
