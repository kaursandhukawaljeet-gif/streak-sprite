# Streak Sprite

Streak Sprite is a habit and task tracking web application built using Lovable and Supabase.

## Purpose
The purpose of the app is to help users organize daily habits and tasks in one place.

## Features
- User login and signup
- Add habits and tasks
- Edit and delete items
- Mark items as completed
- Data stays saved after refresh
- Supabase backend integration

## Technologies Used
- Lovable
- Supabase
- JavaScript
- HTML
- CSS
- GitHub
- Vercel

## Public App Link
https://streak-sprite-tool.lovable.app

## How It Works
Users can sign up or log in, then create habits and tasks. The app saves the data using Supabase, so the information stays available even after refreshing the page.
